About the Project

AI-Powered Forecasting for a Greener Grid

Our system predicts hourly solar and wind power output using a dataset from Open Power System Data covering Germany — the world leader with 46% renewable energy share. Multiple ML and DL models are benchmarked to find the best predictor for each energy type.

Solar generation forecasting with 98.2% accuracy
Wind generation prediction with R² ≈ 0.99

Technology

Models & Techniques

Six algorithms benchmarked — the best selected per energy type.

LSTM / BiLSTM

Long Short-Term Memory networks capture temporal dependencies in energy time-series data.

Deep Learning
CNN-LSTM

Convolutional layers extract spatial features; LSTM layers model sequential patterns.

Deep Learning
Random Forest

Ensemble of decision trees. Best for solar prediction — fast, robust, R² ≈ 0.98.

Ensemble
Support Vector Regressor

SVM with RBF kernel. Best performer for wind energy regression tasks.

Machine Learning
GAN

Generative Adversarial Networks synthesise new training samples to augment sparse data periods.

Generative AI
ARIMA / SARIMAX

Classical time-series baselines used to benchmark against deep learning approaches.

Statistical
Workflow

How It Works

01
Data Preprocessing

50,401 hourly records cleaned, null-filled, and scaled using MinMaxScaler. Correlation analysis + feature importance applied.

02
Model Training

Six models trained with cross-validation. KerasTuner Hyperband used for LSTM hyperparameter optimisation.

03
Prediction & Evaluation

Best models selected by RMSE, MAE, MAPE and R². Live API serves predictions through the web interface.
